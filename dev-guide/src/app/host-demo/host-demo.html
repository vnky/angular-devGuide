@HostListener & @HostBinding

Every component has a host element (here: <app-host-card>). These decorators talk to that outer tag without extra wrapper divs.

@HostBinding

Sets a property on the host. Classes, attributes, or styles on <app-host-card> — for example class.is-hovered or aria-label.

@HostListener

Listens to events on the host. Same as adding (click) on the component tag in a parent, but defined inside the component class (e.g. click, mouseenter).

Try it

Hover, click, and press the card. Inspect the element in DevTools to see host classes change.

Minimal example

@HostBinding('class.active') isActive = false;

@HostListener('mouseenter')
onEnter() { this.isActive = true; }

@HostListener('mouseleave')
onLeave() { this.isActive = false; }
