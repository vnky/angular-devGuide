@HostListener

@HostListener registers a method on the component’s host element (or on document, window, etc.) so you keep DOM wiring in the class instead of repeating (event) in every parent template.

Host target (default)

@HostListener('click') runs when the user interacts with <app-host-event-zone> — the outer DOM node Angular creates for this component.

Tab to focus the zone, then press letter keys — keydown is also on the host.

Global target

@HostListener('window:scroll') listens on the window. Useful for scroll-spy headers or infinite scroll — still declared on the component class.

Scroll the page to see the counter increase.

Compared to the template

<app-my-widget (click)="onClick($event)" />

<!-- same idea, but inside the widget class: -->

@HostListener('click', ['$event'])
onClick(event: MouseEvent) { ... }

See also /host for @HostBinding together with listeners.
